# 🤝 Katkıda Bulunma Rehberi

CruiserIsoBox'a ilgi gösterdiğin için teşekkürler! 🚢
Kod yazmak zorunda değilsin. Hata bildirmek, çeviri yapmak, logo çizmek ya da fikir önermek de çok değerli.

## 💡 Nasıl katkı verebilirsin?

| Katkı türü | Nasıl? |
|---|---|
| 🐛 **Hata bildirimi** | [Issues](https://github.com/KULLANICIADI/cruiser-isobox/issues) sayfasından yeni bir issue aç |
| ✨ **Özellik fikri** | [Discussions](https://github.com/KULLANICIADI/cruiser-isobox/discussions) sayfasında paylaş |

| 📖 **Dokümantasyon** | README ve kılavuzlardaki hataları düzelt, eksikleri tamamla |
| 💻 **Kod** | Aşağıdaki adımları izle |

## 🐛 Hata bildirirken

Hatayı hızlı çözebilmemiz için şunları yaz:

- İşletim sistemi ve sürümü (örneğin Windows 11, Ubuntu 24.04)
- CruiserIsoBox sürümü
- Kullandığın USB belleğin markası ve boyutu
- Hangi ISO ile sorun yaşadın
- Ne yapmaya çalıştın, ne oldu, ne olmasını beklerdin
- Varsa ekran görüntüsü ya da hata mesajı

> ⚠️ Hata ararken USB'deki verilerini yedekle. Disk işlemleri veri kaybına yol açabilir.

## 💻 Kod katkısı

1. Depoyu **fork** et
2. Kendi bilgisayarına klonla:
   ```bash
   git clone https://github.com/KULLANICIADI/cruiser-isobox.git
   cd cruiser-isobox
   ```
3. Yeni bir dal aç:
   ```bash
   git checkout -b ozellik/kisa-aciklama
   ```
4. Değişikliklerini yap ve test et
5. Anlaşılır bir mesajla commit et:
   ```bash
   git commit -m "Ekle: ISO başına profil seçimi"
   ```
6. Fork'una gönder ve **Pull Request** aç:
   ```bash
   git push origin ozellik/kisa-aciklama
   ```

Bu proje **GPLv3** lisansı altındadır. Katkı göndererek, kodunun da aynı lisansla yayınlanmasını kabul etmiş olursun.

Başka bir projeden kod getiriyorsan:
- Lisansının GPLv3 ile uyumlu olduğundan emin ol
- Orijinal telif ve lisans notlarını silme
